
# Task-Management

Task Management is a simple web application that helps users manage their daily tasks. You can add new tasks, edit existing ones, delete tasks, set priorities, choose due dates, and track task progress.

I built this project to practice my HTML, Tailwind CSS, and JavaScript skills while learning how to create useful web applications.

## Features

- Add new tasks with a name, priority, due date, and status.
- Edit tasks whenever information needs to change.
- Delete tasks with a confirmation message.
- Track tasks as Pending, In Progress, or Completed.
- View a dashboard showing the total number of tasks and their current status.
- Validate required fields before adding or updating tasks.
- Use a clean and responsive interface.

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (Vanilla JavaScript)

## How to Use

1. Enter a task name.
2. Select a priority and due date.
3. Choose the task status.
4. Click **Add Task** to create a new task.
5. Click **Edit** to change a task's information.
6. Click **Update Task** to save your changes.
7. Click **Delete** to remove a task.
8. Check the dashboard to see your task counts and progress.
